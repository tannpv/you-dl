You-DL installation

macOS: choose package matching your Mac (arm64 for Apple Silicon, x64 for Intel).
Open DMG, drag You-DL into Applications, then launch from Applications.
Eject disk image after copying. To remove, quit and move You-DL.app to Trash.

Windows 11 x64: run You-DL-...-Setup.exe. Installer uses your user profile and
does not need administrator rights. Start Menu shortcut is included; desktop
shortcut is optional. Uninstall from Settings > Apps > Installed apps.
Run a newer installer to upgrade the same installation.

Python, FFmpeg and Node are included. You do not need to install developer tools.
Downloaded videos/audio remain in your chosen save folder when uninstalling.

Preview signing: consult adjacent package .json for signing/notarization status.
Unsigned Windows builds may show SmartScreen warnings. Mac distribution without
notarization may be blocked by Gatekeeper. No protection needs to be disabled.
Use only packages from your private tannpv/you-dl GitHub release.
